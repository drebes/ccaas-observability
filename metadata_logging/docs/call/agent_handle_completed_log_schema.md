# CCAIPCallLog_agent_handle_completed

Markdown representation of the CCAIPCallLog_agent_handle_completed event schema.

## Schema Structure

| Field Path | Type | Description |
| :--- | :--- | :--- |
| `insertId` | `string` | Unique stable identifier for the log entry generated by the ingestion pipeline. |
| `jsonPayload.event` | `object` | Event wrapper containing name, GCS source, and milestone specific payload. |
| `jsonPayload.event.name` | `string` | The specific milestone event name. |
| `jsonPayload.event.gcs_source` | `string` | Source GCS URI of the raw metadata file. |
| `jsonPayload.event.payload` | `object` | Milestone-specific metrics and attributes payload. |
| `jsonPayload.event.payload.call` | `object` | Reference metadata for the call session. |
| `jsonPayload.event.payload.call.id` | `integer` | Unique identifier of the call session. |
| `jsonPayload.event.payload.call.type` | `string` | The channel/type of the call session. |
| `jsonPayload.event.payload.call.lang` | `string` | The ISO 689 language code used during the call session. |
| `jsonPayload.event.payload.call.uuid` | `Nullable<string>` | UUID identifier of the call session. |
| `jsonPayload.event.payload.agent_handle` | `object` | Milestone-specific metrics and attributes payload for agent_handle. |
| `jsonPayload.event.payload.agent_handle.id` | `integer` | the identifier of the handle duration |
| `jsonPayload.event.payload.agent_handle.agent_id` | `integer` | the identifier of the agent who handled the call |
| `jsonPayload.event.payload.agent_handle.acw_duration` | `integer` | Metric property: acw_duration. |
| `jsonPayload.event.payload.agent_handle.bcw_duration` | `integer` | Metric property: bcw_duration. |

| `jsonPayload.event.payload.agent_handle.transfer` | `boolean` | whether the call was handled via a transfer |
| `jsonPayload.event.payload.agent_handle.transfer_id` | `Nullable<integer>` | the identifier of the associated transfer |

| `jsonPayload.message` | `string` | N/A |

| `resource.labels` | `object` | Monitored resource specific labels. |

| `timestamp` | `string` | Precise ISO UTC Z timestamp of the telemetry event. |
