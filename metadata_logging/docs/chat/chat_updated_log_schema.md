# CCAIPChatLog_chat_updated

Markdown representation of the CCAIPChatLog_chat_updated event schema.

## Schema Structure

| Field Path | Type | Description |
| :--- | :--- | :--- |
| `insertId` | `string` | Unique stable identifier for the log entry generated by the ingestion pipeline. |
| `jsonPayload.event` | `object` | Event wrapper containing name, GCS source, and milestone specific payload. |
| `jsonPayload.event.name` | `string` | The specific milestone event name. |
| `jsonPayload.event.gcs_source` | `string` | Source GCS URI of the raw metadata file. |
| `jsonPayload.event.payload` | `object` | Milestone-specific metrics and attributes payload. |
| `jsonPayload.event.payload.chat` | `object` | Reference metadata for the chat session. |
| `jsonPayload.event.payload.chat.id` | `integer` | Unique identifier of the chat session. |
| `jsonPayload.event.payload.chat.type` | `string` | The channel/type of the chat session. |
| `jsonPayload.event.payload.chat.lang` | `string` | The ISO 689 language code used during the chat session. |
| `jsonPayload.message` | `string` | N/A |
| `resource` | `object` | Google Cloud resource monitored resource metadata envelope. |
| `resource.type` | `string` | The monitored resource type identifier (always contactcenteraiplatform.googleapis.com/ContactCenter). |
| `resource.labels` | `object` | Monitored resource specific labels. |
| `resource.labels.location` | `string` | The GCP region/location of the ContactCenter resource. |
| `resource.labels.resource_container` | `string` | The GCP project ID hosting the ContactCenter resource. |
| `resource.labels.resource_id` | `string` | The identifier of the ContactCenter resource instance. |
| `timestamp` | `string` | Precise ISO UTC Z timestamp of the telemetry event. |
| `severity` | `string` | The severity level of the log entry (e.g. INFO, ERROR). |
| `logName` | `string` | The Google Cloud Logging resource path for the metadata log. |
